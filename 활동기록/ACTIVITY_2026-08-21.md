# 2026-08-21 활동 기록

## 목표

- 배포 코드를 공통 package로 재편.
- 듀얼 카메라 105D 실물 read-only 완주.

## 원인 수정

- Fingertip observation이 다른 Wuji URDF의 tip frame을 사용.
- 엄지 3.0 mm, 검지 0.7 mm frame 차이 확인.
- 물리 접촉이 아니라 FK 관측 배선 문제로 판정.

## 변경

- `mujoco_deploy`를 `Deploy/` 구조로 재편.
- `run → backends → policy/vision → common` import 방향 고정.
- Deploy rig frame과 dual-camera stick pose provider 구현.
- `run_hand_policy_real.py`, `run_mujoco_policy.py` 신설.
- Per-joint slew guard 적용.

## 결과

- Camera→Stick pose→105D obs→ONNX→20D target 150 step read-only 완주.
- Policy 30 Hz 유지.
- 관측·추론 처리시간이 tick 예산 안에 들어옴.
- MuJoCo release 시 stick drop, release-never 시 고정 확인.

## 판단

- 모델 shape 일치만으로 배포 계약 일치 판정 불가.
- Tip frame, joint order, limits, action scale까지 검증 필요.

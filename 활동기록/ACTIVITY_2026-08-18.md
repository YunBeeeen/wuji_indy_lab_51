# 2026-08-18 활동 기록

## 목표

- Hand-real 105D 정책의 Isaac↔MuJoCo 불일치 원인 규명.
- 실물 Wuji 한계 기반 Finger-Reach 신설.

## 진단

- Observation slice, normalization, reset pose, quaternion folding, action decode 일치.
- 정책 실행 시 MuJoCo에서 stick을 놓치는 문제 지속.
- Solver dt보다 Isaac과 MuJoCo가 서로 다른 hand model을 사용한 것이 핵심 원인.

## 변경

- 실물 factory joint limit을 observation normalization과 command limit 기준으로 채택.
- 실물 limit이 vendor description보다 넓음을 검증.
- Controller gain과 MuJoCo solver 설정 정리.
- Middle finger 4D action, 15D observation의 `finger_reach` task 신설.
- Palm-frame target observation 사용.
- Stick 없는 MuJoCo scene 분리.

## 결과

- Finger-reach 첫 run은 iter 155 정점 후 성능 회귀.
- Policy update와 action saturation 진단 필요성 확인.
- Isaac reset observation 결정론적 검증.

## 판단

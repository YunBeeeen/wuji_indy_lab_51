# Activity 2026-07-21

## 코드 수정 — chopstick lift 성공 보상구조를 Box-Transport에 이식

젓가락(one-stick) 태스크에서 lift가 성공한 뒤, 그 성공 보상구조(검지·엄지를 명시적으로
지정한 balanced tripod 파지 gate)를 Box-Transport로 복사해 붙여넣음. 이전 코드는
`box_mdp_cfg backup.py`로 백업해 둠. 대상 파일:
`nrmk_isaaclab_wuji/isaac_neuromeka/tasks/manipulation/grasp/box_mdp_cfg.py`.

### 파지 gate 전면 교체 (핵심)
- 기존: 12-point 평균 cage(`mdp.object_in_finger_cage`, `BOX_CAGE_BODIES` 5-body 평균).
- 변경: **balanced tripod = `min(엄지–검지 cage, 엄지–중지 cage)`**
  (`fg_mdp.balanced_tripod_cage_gate`). 엄지 하나로 1/3 크레딧을 먹던 파밍을 막고, 두 선분이
  동시에 물려야 gate가 열리도록 함.
- 신규 선분 정의: `BOX_INDEX_CAGE_BODIES`(엄지끝+검지끝+검지link3),
  `BOX_MIDDLE_CAGE_BODIES`(엄지끝+중지끝+중지link3).
- 신규 클래스(모두 balanced gate 사용): `BalancedObjectToGoalProgressReward`,
  `BalancedObjectOrientationProgressReward`, `BalancedObjectAtGoalHeld`,
  `balanced_object_goal_proximity`.

### 보상 항목별 변경 (before → after, 근거)
- `finger_cage_hold`: `mdp.object_in_finger_cage` → `fg_mdp.balanced_tripod_cage_gate`,
  weight 15 (유지).
- `cube_lift`: `mdp.object_lift_in_cage` → `fg_mdp.object_lift_in_balanced_tripod_cage`,
  weight **50 → 150**, lift_height 0.08. (lift 가중치는 이후 "조금 낮춤" 방향으로 재조정 여지)
- `cube_transport`: `mdp.ObjectToGoalProgressReward` → `BalancedObjectToGoalProgressReward`,
  weight **4000 → 8000**. 근거: 이식본이 "잘 들지만 position 수렴 안 함" → position error를
  맞췄을 때 보상을 더 주도록 상향.
- `box_orientation`: `mdp.ObjectOrientationProgressReward` →
  `BalancedObjectOrientationProgressReward`, **activation_distance 0.10 → 0.015**
  (latch 조건 10cm → 1.5cm). 근거: latch가 10cm로 너무 약해 한 번 켜지면 goal에서 먼 채로
  orientation만 다듬어 보상을 먹고 position은 수렴 안 함 → latch를 빡빡하게 조임.
- `index_grip` / `thumb_grip`: `fg_mdp.FingertipGripProgressReward` **신규**, weight 40 each.
  검지·엄지를 물체 로컬 rear grip region 최근접점으로 유도 (dense shaping, success에는 미포함).
- `hand_floor`: weight **1.0 → 0.0**, clearance **0.02 → 0.01**.
- `success`: `mdp.ObjectAtGoalHeld` → `BalancedObjectAtGoalHeld`.
  goal_radius 0.05, gate_threshold 0.3, hold_steps 15, **ori_limit 0.2618(15°) 유지**.

### 관측 / 크기 / 기타
- 관측 +6: `index_grip_error`(3) + `thumb_grip_error`(3) → **policy obs 67 → 73**.
- 박스 크기 기본값: width `(0.03,0.06)` / ratio `(1.5,3.0)` / length `None`
  → **width `(0.02,0.02)` / ratio `(1,1)` / length `(0.18,0.18)` = 2×2×18cm 얇은 스틱**.
- `_HALF_FALLBACK` `(0.03,0.03,0.03)` → `(0.01,0.09,0.01)` (스틱 fallback).
- 신규 파일 `chopstick_mdp_cfg.py`(독립 젓가락 태스크, untracked).

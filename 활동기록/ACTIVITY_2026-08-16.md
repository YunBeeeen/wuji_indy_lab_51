# 2026-08-16 활동 기록

## 목표

- Hand-real의 최종 sim-to-real observation/action 계약 확정.

## 변경

- Actor observation을 quaternion history 기반 105D로 복원.
- 사각 stick의 local +Y 90° 대칭 4개 중 reference-nearest branch 선택.
- Quaternion을 `w≥0`으로 canonicalize.
- Reward·success orientation은 directed-axis 유지.
- Current-joint residual scale을 관절군별 설정.

## 최종 계약

| 항목 | 설정 |
|---|---|
| Observation | 105D |
| Action | 20D |
| Joint1/2 scale | 0.10 rad |
| Joint3 scale | 0.20 rad |
| Joint4 scale | 0.15 rad |
| Quaternion | palm-frame `wxyz` |
| Policy rate | 30 Hz |

## 결과

- Stick tip/tail 방향과 pose history 유지.
- 물리적으로 동치인 shaft roll 분기 안정화.
- 101D ONNX·adapter 비호환 명시.

## 판단

- Quaternion은 actor 정보, directed-axis는 성공 기준.
- Action semantics가 다른 checkpoint는 fresh 학습.
- Deploy adapter도 105D 계약으로 동시 갱신 필요.

# 2026-08-16 — `hand_real` quaternion 관측과 distal action scale 정리

## 현재 계약

- `hand_real`/`hand_final` actor 관측은 **105D**다.
  - joint normalized position history: 40 (`previous`, `current`)
  - fingertip palm-frame position: 15
  - Stick1/2 palm-frame `xyz+wxyz` history: 14+14
  - last applied raw action: 20
  - OPEN/CLOSE one-hot: 2
- Stick quaternion은 사각 단면의 local `+y`축 주위 90도 회전 4개를 물리적으로 동치로 보고,
  `pose_005` reference에 가장 가까운 branch를 고른 뒤 `w>=0`으로 canonicalize한다.
- quaternion은 reward에서 특정 shaft roll을 강제하기 위한 값이 아니다. 정책이 접촉면과 전체
  자세를 구분하고 previous/current pose에서 회전 변화를 추론할 수 있게 관측에 제공한다.
- Stick reference reward와 success/termination의 orientation error는 계속
  `directed_axis`다. 즉 local `+y` 장축 방향은 맞추되 장축 기준 roll은 성공 조건에서 제외한다.

## action scale 최종 A/B 설정

`hand_real` 계열의 current-joint residual action은 다음과 같다.

```text
Joint1/2: q_target = q_current + 0.10 * action
Joint3:   q_target = q_current + 0.20 * action
Joint4:   q_target = q_current + 0.15 * action
```

- Joint3의 현재 Kp는 `0.75`이므로 최대 0.2 rad P-step은 약 `0.15 N·m`이며 현재 Joint3
  effort limit보다 작다.
- Joint4 Kp/Kd는 사용자가 별도로 조정했다. Joint4는 0.15 rad step을 기준으로 튜닝했으므로
  action scale도 0.15로 맞췄다. `effort_limit_sim`은 최종 applied torque cap으로 유지된다.
- OPEN/CLOSE 전환 횟수는 이번 A/B에서 바꾸지 않는다. action scale 효과를 먼저 분리해서 보고,
  필요할 때 별도 fresh run에서 10초당 2회 전환을 비교한다.
- action semantics 변경이므로 Joint3/4가 모두 0.2였던 checkpoint에서 resume하지 않고 fresh
  학습으로 비교한다.

적용 위치:

```text
nrmk_isaaclab_wuji/isaac_neuromeka/tasks/manipulation/hand_grasp/hand_real_env_cfg.py
HAND_REAL_ACTION_SCALE
apply_hand_real_contract()
```

이 helper를 공유하는 `hand_real`, `hand_final`, `hand_play`에 적용된다. 공용 `hand_move`의
all-joint scale 0.1은 변경하지 않았다.

## Stick frame 확인

- Isaac Stick은 별도 geometry/CoM offset 없는 `7 x 180 x 7 mm` Cuboid다.
- rigid-body root origin과 geometric center 및 CoM이 일치한다.
- local 장축은 Y축이며 center 기준 distal tip은 `+0.09 m`, tail은 `-0.09 m`다.
- 과거 Stick1 reference/pivot 5 mm axial A/B 상수
  `STICK1_REFERENCE_AXIAL_SHIFT_M`은 현재 `0.0`으로 원복되어 있다.

## 호환성과 검증

- 101D directed-axis ONNX/MuJoCo adapter는 현재 105D quaternion policy와 입력 shape가 다르다.
  새 105D 학습 모델을 배포할 때 MuJoCo/실물 observation adapter와 ONNX도 함께 갱신해야 한다.
- `hand_real_env_cfg.py`에 대해 `py_compile`과 `git diff --check`를 통과했다.
- 프로젝트 원칙에 따라 Isaac simulation/train/play는 Codex가 실행하지 않았고 사용자 run으로
  동작과 학습 지표를 확인한다.

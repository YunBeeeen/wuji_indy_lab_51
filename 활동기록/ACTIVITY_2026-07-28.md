## 2022 chopstick 논문 reward와 현재 STATE B 비교

- 대상은 Yang et al., *Learning to Use Chopsticks in Diverse Gripping Styles*
  (SIGGRAPH 2022, arXiv:2205.14313v3)와 공식 저장소
  `chopsticks-research2022/learning2usechopsticks`임. 상세 수식과 구현 비교는
  `thesis.md`의 동명 절에 기록함.
- 논문 action은 선택한 gripping pose에 정책의 corrective offset을 더하는
  reference-centered residual임. 현재 `pose_005 PD target + action×0.1 rad`와 같은 계열임.
- 본문 reward는 hand pose, 두 stick pose, object pose, 지정 fingertip-contact point
  거리의 음수 cost 합을 지수화함. gripping-pose 평가에는 물체가 없으므로 object 항을 빼고,
  세 개의 1초 open-close motion 추종 평균 reward를 BO 후보 점수로 사용함.
- standard topology는 `(thumb,index,middle,ring,little)=(1,1,1,2,0)`으로,
  엄지·검지·중지→Stick1, 약지→Stick2, 새끼 미사용임.
- 공식 코드는 지수형 hand/Stick1/Stick2/object/contact sub-reward를 곱하고 object 접촉
  bonus를 더함. 한 조건을 버리고 다른 연금을 먹기 어렵게 모든 조건을 결합하는 구조임.
- 논문은 fingertip 접촉점만 명시적으로 최적화하며 valley 접촉은 물리 학습에서 창발시킴.
  현재 Wuji STATE B의 `finger1_link2↔Stick2`와 `palm_link↔Stick2` 필수 anchor는
  `pose_005` contact-pair probe로 확인한 아래 stick 고정 접촉을 격리 검증하기 위한
  프로젝트 고유 adaptation임.
- 현 reward의 6-contact full gate가 논문의 곱형 결합 역할을 일부 수행하므로 즉시 구조를
  바꾸지는 않음. 다음 변경 후보는 broad contact OR 추가가 아니라 joint reference,
  Stick1/2 reference, semantic contact를 곱형/coupled reward로 묶는 것임.
- 이후 STATE C는 아래 Stick2 anchor를 유지한 채 위 Stick1과 관련 손가락에 시간에 따른
  open-close reference trajectory를 주는 방식이 논문과 가장 직접적으로 대응함.

# 2026-07-13 활동 기록

## 목표

- Palm-facing 캠핑, action 발산, 비제어 손가락 충돌 원인 해결.
- Grasp→lift 단계화 기준 확립.

## 원인

- 절대형 `palm_facing`이 전체 reward 대부분을 차지해 원거리 캠핑 발생.
- `clip_actions` 부재와 작은 action scale로 raw action 발산.
- 정책이 제어하지 않는 약지·새끼가 cube를 밀어냄.
- 잘못된 facing gate가 signed progress의 telescoping을 깨뜨림.
- Raw lift 신호가 전체 학습에서 0인 상태.

## 변경

- Facing을 signed progress로 전환.
- Arm manipulability penalty 추가.
- `clip_actions=1.0`, action scale 재설계.
- 중지 목표를 약지·새끼에 복제하는 mimic coupling 적용.
- raw/applied action, target, actual, torque 진단 추가.
- 양수 progress에만 facing gate 적용.
- `Indy-Wuji-Chopsticks-Grasp` 초기 task 신설.

## 결과

- Action 수정 후 최초 cage hold 발생.
- 접촉 폭발처럼 보인 현상이 정책 명령 발산이었음을 확정.
- Reward staging도 curriculum으로 사용할 수 있음을 정리.

## 판단

- Reward weight 조정보다 raw 신호 존재와 action 추종 먼저 확인.
- Reward·action 의미 변경 시 resume 금지.

# 2026-08-28 활동 기록

## Hand-setting 추가 학습

### 목표

- 편 손에서 two-stick pregrasp를 획득하는 추가 학습 진행.
- 새끼손가락이 약지 경로를 막는 영향을 단일변수 A/B로 확인.

### 조건

- Run `2026-08-28_09-40-28`: model 0~850 저장.
- Run `2026-08-28_11-36-28`: model 0~250 저장.
- 4096 env, episode 8초, learning rate 0.001, entropy 0.001 사용.
- Pair gate threshold 0.65, functional-contact force scale 0.10 N 유지.
- Contact reward는 min 17, mean 5, hard mean 8, hard-face 15 사용.

### 변경

- 두 run의 환경 차이를 새끼손가락 관절 credit 하나로 제한.
- Missing-16 joint linear·fine reward에서 마지막 4개 새끼손가락 weight를 `1.0→0.25`로 변경.
- 검지·중지·약지 12관절 weight 1.0 유지.
- Observation 105D, action 20D, reset, contact reward, PPO 설정 유지.

### 판단

- 새끼손가락이 약지를 방해하지 않도록 유도하면서 지지 역할은 완전히 제거하지 않는 A/B.
- 추가 학습 진행 중으로 best checkpoint와 안정 수렴 여부 미확정.
- Stage-1 진입, functional contact, hard-face contact를 함께 판독 예정.

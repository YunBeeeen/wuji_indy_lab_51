## Direct와 Manager-Based 차이

- Direct 방식은 env class 안에 직접 구현함.
- Direct 방식은 `_get_observations`, `_get_rewards`, `_apply_action`, `_reset_idx` 같은 함수를 직접 짬.
- Manager-based 방식은 공통 env class를 쓰고 cfg와 mdp 함수만 바꿈.
- Manager-based 방식은 `Cfg + mdp 함수 + assets` 조합으로 task를 만듦.
- 현재 `Indy-Wuji-Reach`는 manager-based 방식임.

## Cfg 의미

- `Cfg`가 붙은 것은 대부분 설정표임.
- `ReachEnvCfg`는 reach task 조립 설정임.
- `RewardsCfg`는 reward term 목록 설정임.
- `ObservationsCfg`는 observation term 목록 설정임.
- `ActionsCfg`는 action term 설정임.
- `CommandsCfg`는 command term 설정임.
- `ArticulationCfg`는 robot asset 설정임.
- `Cfg`는 직접 계산하지 않음.
- `Cfg`는 manager에게 어떤 함수와 파라미터를 쓸지 알려줌.

## Command와 Action 이해

- command는 목표임.
- action은 agent가 내는 제어 입력임.
- 현재 command는 `ee_pose`임.
- `ee_pose`는 target position + target orientation임.
- 현재 action은 joint0~joint5 joint position action임.
- command는 Cartesian pose임.
- action은 joint 제어 입력임.
- command와 action은 직접 비교 대상이 아님.
- command manager 내부 command는 7D pose임.
- policy observation에는 command 중 xyz position 3D만 넣음.

## Reward 이해

- reward는 action과 command를 직접 비교해서 나오지 않음.
- reward는 action을 robot에 적용한 뒤 robot state와 command target을 비교함.
- 현재 주요 비교는 `link6` 현재 pose와 `ee_pose` target pose 사이 비교임.
- position reward는 현재 `link6` 위치와 target 위치 거리 기반임.
- orientation reward는 현재 position-only baseline에서 제거함.
- `action_rate`는 command와 action 비교가 아님.
- `action_rate`는 이전 action과 현재 action 차이에 대한 penalty임.
- `joint_vel` reward penalty는 현재 제거함.
- `end_effector_speed` reward penalty는 현재 제거함.
- TensorBoard에는 weighted reward와 raw unweighted reward를 둘 다 기록하도록 변경함.
- weighted reward는 `Episode_Reward/*`에 기록됨.
- raw unweighted reward는 `Episode_Reward_Raw/*`에 기록됨.
- reward std는 `Episode_Reward_Std/*`에 기록됨.

## 현재 Reach MDP 구성

- command는 `ee_pose` target임.
- command는 6~10초마다 resampling됨.
- observation은 `joint_pos`, `pose_command`, `action_history`임.
- `joint_pos`는 arm 6축만 봄.
- `pose_command`는 command xyz 3D만 봄.
- `action_history`는 previous action 6D만 봄.
- observation history와 noise는 현재 policy observation에서 제거함.
- action은 arm 6축 joint position action임.
- reward는 position tracking과 action rate penalty만 사용함.
- termination은 `time_out` 중심임.
- reset은 scene을 default 상태로 돌리는 흐름임.

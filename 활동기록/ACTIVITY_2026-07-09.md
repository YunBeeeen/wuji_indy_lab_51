# 2026-07-09 활동 기록

## 목표

- Isaac Lab manager-based MDP 실행 구조 이해.
- Reach task를 최소 관측·액션·보상으로 정리.

## 변경

- action을 Indy arm 6축으로 제한.
- 관측을 joint position 6D, target xyz 3D, previous action 6D의 15D로 구성.
- orientation, joint velocity, end-effector speed reward 제거.
- raw·weighted reward와 reward 표준편차 로깅 추가.

## 결과

- command → action → physics → observation/reward 흐름 정리.
- reward가 action 자체가 아니라 적용 후 robot state와 command를 비교함을 확인.
- position-only reach baseline 확립.

## 판단

- cfg와 MDP 함수 역할을 분리해서 관리.

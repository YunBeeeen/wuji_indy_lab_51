# 2026-07-11 활동 기록

## 목표

- 접근하지만 잡지 않는 Cube-Grasp 원인 규명.
- 파지를 직접 유도하는 reward로 교체.

## 원인

- Cube 중심은 손끝이 도달할 수 없는 내부 목표.
- 접촉으로 cube가 밀리면 중심 거리가 증가해 접촉이 감점.
- 엄지 가중치가 커서 엄지만 중심에 넣는 해법 선택.
- progress 포화와 best-only 적립으로 지연·왕복 farming 발생.

## 변경

- fingertip-center reward 제거.
- 엄지–대향 손가락 가상점과 box SDF 기반 cage reach/hold 도입.
- 유도 항은 signed progress, 유지 항은 absolute reward로 분리.
- final/min/max 접촉·거리·opposition metric 추가.
- action·PhysX 진단 출력 보강.

## 결과

- Cube가 엄지–중지 사이로 들어오는 동작 확인.
- 물리 문제가 아니라 reward 목표가 파지를 처벌한 문제로 판정.

## 다음

- Fresh 학습 사용.
- 검지 참여와 손바닥 방향을 별도 metric으로 확인.

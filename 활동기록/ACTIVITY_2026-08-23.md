# 2026-08-23 — 체크포인트 교체 안전장치, hand_real2 750pt 배포

> Isaac 학습과 실물/카메라 실행은 사용자가, 코드 작성과 로그 판독은 Claude가 맡았다.
> 에이전트 함정은 `Deploy/CLAUDE.md`와 루트 `CLAUDE.md`에 따로 적었다.

## 1. 문제 — "정책만 바꿔 끼우면 되나"

사용자 질문: *"앞으로 deploy 모델들을 바꿔가면서 테스트할건데 바꿔도 바로 실행되도록
구조가 되어있음? obs 똑같고 action space도 똑같아 걍 policy만 다름"*

`--policy` 경로만 바꾸면 **돌기는 한다.** `OnnxPolicy` 가 입출력 shape 105/20 을
검사하므로 엉뚱한 파일은 로드에서 걸린다. 그런데 **shape 는 거의 아무것도 아니다.**
네트워크가 안 들고 다니는 것들:

| 네트워크가 안 갖고 있는 것 | 배포 쪽 출처 |
|---|---|
| pregrasp(리셋) 자세 | `Deploy/common/isaac_reset.py` 상수 |
| 관절별 액션 스케일 | `policy_contract.ACTION_SCALE_RAD` |
| 20개 숫자의 **관절 순서** | `policy_contract.POLICY_JOINT_NAMES` |
| 관측 정규화 범위 | `OBSERVATION_NORMALIZATION_LIMITS` |
| OPEN/CLOSE 스케줄 | `run_hand_policy_real` CLI 기본값 |

전부 하드코딩 상수이고, **어긋나도 예외가 안 난다.** 손은 부드럽게, 틀리게 움직인다.
이 스택에서 제일 비싼 실패 양상이다 — 튜닝 문제처럼 보이기 때문이다.

## 2. `Deploy/tools/verify_policy_contract.py` (신설)

Isaac 이 런마다 남기는 `params/env.yaml` 을 배포 상수와 대조한다. 체크포인트를
갈아끼우기 전에 돌린다.

| 블록 | 검사 |
|---|---|
| `[ACTION]` | 관절 순서, `preserve_order`, `clamp_to_limits`, joint4 하한 override, **관절별** 액션 스케일 (스칼라로 학습한 런을 따로 구분) |
| `[OBS]` | 관측 term 구성, history_length |
| `[POSE]` | env.yaml pregrasp vs `ISAAC_PREGRASP_JOINT_POSITIONS_RAD` |
| `[SCHEDULE]` | **학습이 본 모드** — `episode_length_s` vs `open_close_start_time_s` + `neutral_before_open_close` |
| `[LIMITS]` | 정규화 출처, 0.95 명령 여백이 의도된 차이라는 주석 |

**게이트가 아니라 도구다.** env.yaml 은 학습 로그 옆에 있어 정리·이동될 수 있고,
파일이 없다고 멀쩡한 주행을 막으면 안 된다. 매 주행 자동 실행이 아니라 사람이
돌리는 검사로 뒀다.

### 실제로 잡은 것 (2026-08-24 재실행 기준)

| 런 | 결과 |
|---|---|
| `hand_real/2026-08-18_23-57-25` (4500pt) | `[DIFF]` pregrasp **77.97 mrad** (`finger2_joint2`) |
| `hand_real2/2026-08-23_16-47-00` (750pt) | `[DIFF]` **NEUTRAL `[0,0]` 만 학습** — `--mode neutral` 로 배포할 것 |
| `hand_real/2026-08-24_09-29-55` (2400pt) | 전부 일치 |

세 건 다 ONNX 로드로는 절대 안 잡힌다.

## 3. pregrasp 를 학습 런에서 읽기

`Deploy/common/isaac_reset.py` 에 `read_pregrasp_from_env_yaml(run_dir)` 추가.

- env.yaml 이 `!!python/tuple` 태그를 달고 나와 `yaml.safe_load` 가 못 읽는다 →
  정규식 파싱. (같은 "`$` 가 개행 앞에서 멈추는" 부류 버그를 파서에서 3번 냈다.
  함정은 `Deploy/CLAUDE.md` 에 적었다.)
- **적용 방식은 사용자가 정했다**: CLI 플래그가 아니라 **상수 한 줄 블록 직접 교체**.
  *"cli로 안 넣고 코드 수정해서 할거라니까 내가 매번 확인도 할 겸 확실하게"*
  → 도구가 붙여넣을 형태로 값을 찍어주고, 교체는 사용자가 한다.
- **이전 pregrasp 는 주석으로 보존한다** (사용자 요청). 되돌릴 때 다시 뽑지 않도록.

## 4. NEUTRAL `[0,0]` 은 "명령 없음"이 아니다

`mode_one_hot` 에 `neutral` 추가. 모드는 OPEN `[1,0]` / CLOSE `[0,1]` /
**NEUTRAL `[0,0]`** 세 상태이고, 세 번째도 학습된 상태다.

`hand_real2` 의 5초 파지/세팅 커리큘럼은 `episode_length_s 5.0 <= open_close_start
5.0` 이라 **NEUTRAL 만 본다.** OPEN/CLOSE 밖에 못 보내는 키보드로는 이 체크포인트를
아예 못 돌린다 → `--mode neutral` 과 키보드 `n` 을 넣었다.

## 5. `deploy_rig.assert_deployable` — 거부에서 경고로

사용자: *"저거 없어도 되는 거 아닌가"*

`--acknowledge-candidate-geometry` 는 리그 상수 중 아직 실측 대조가 안 끝난 항목이
있으면 주행을 **거부**하고, 플래그를 붙이면 통과시키는 구조였다. 매 런 거부당하고
매 런 플래그로 넘긴다면 그건 신호가 아니라 소음이다. `raise` → 경고 출력으로 바꾸고,
플래그는 **그 경고를 죽이는 역할만** 남겼다.
